# LLM_Eval_04_Production_Evals

Practical guide to evaluating LLMs in production. Covers online traffic sampling strategies, input and output distribution drift detection, golden-set curation and versioning, regression CI with deploy gates, sampled human review workflows, building feedback loops from thumbs-up/down signals, eval observability dashboards and alerting, and cost models for continuous evaluation at scale.

**Live site:** https://brendanjameslynskey.github.io/LLM_Eval_04_Production_Evals/

Part of the [LLM Evaluations sub-hub](https://github.com/BrendanJamesLynskey/LLM_Hub_Evaluations)
